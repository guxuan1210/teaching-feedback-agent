# 教学反馈数据采集 Demo

一个本地运行的 FastAPI + SQLite 应用，用于维护教学名单、批量录入晚辅/专项反馈、查看历史记录，并把筛选结果导出为 Excel。

## 技术栈

Python 3.11、FastAPI、Jinja2、SQLAlchemy、SQLite、openpyxl、pytest。

## 安装与运行

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m app
```

启动后访问 http://127.0.0.1:8000。

`python -m app` 会自动创建 `data/` 目录、升级 `data/teaching_demo.db`，并写入 85 条反馈指标及教学参考字典后启动服务。参考字典包括零阶至九阶、6 个晚辅档位，以及入学测评的 2 个模块、16 个维度和 96 条评分锚点。

## 数据库位置

- 数据库文件：`data/teaching_demo.db`（SQLite，WAL 模式，外键已启用）。
- 指标字典：`db/seed_indicators.sql`（首次启动自动写入，之后采用「缺则插入」语义，不覆盖已有行）。
- 教学参考字典：`db/seed_reference_data.sql`（阶段、档位和入学测评评分标准，同样采用「缺则插入」语义）。

## Excel 导出

在「历史记录」页用筛选条件过滤后，点击「导出 Excel」即可下载包含 4 个工作表（学生、班级、晚辅反馈、专项反馈）的 `.xlsx` 文件；导出会沿用当前筛选条件（含日期、班级、学生、类型、状态）。

## 安全备份

在应用停止运行后，直接复制 `data/teaching_demo.db` 即可完成备份；不要在应用运行期间拷贝（WAL 模式下可能有未合并的日志）。

## 登录与权限

启动后访问 http://127.0.0.1:8000 会跳转到登录页。

- **初始管理员**：`管理员` / `admin123`（首次启动自动创建，登录后请在「教师」页修改密码）。
- **权限分层**：角色为 `管理员` 或 `校区负责人` 的账号可访问全部数据与「基础信息」管理页；普通老师只能看到自己负责的班级、自己创建的场次，以及对应的反馈历史与导出结果。
- 密码使用 PBKDF2-SHA256 加盐哈希存储，会话通过服务端签名 Cookie 维持；历史教师若 `password_hash` 为空则不能登录。

## 说明

本项目是一个数据采集演示，权限控制面向本地试用场景；默认密码、默认会话密钥和当前密码策略不适合生产环境（如需上线，建议补充 HTTPS、更强的会话密钥与密码策略）。
